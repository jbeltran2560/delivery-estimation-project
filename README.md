#Delivery-estimation-project
A fall semester project utilizing git and github in order to make a list of past deliveries and make calculations from it
Project is created by Jesus Beltran

#Prerequisites
For the connected files to work as intended, both PHP 8.5.12 and XAMPP 8.5.12 is required.

#Running the application
When using XAMPP, make sure the project files are in a folder inside htdocs, as well as the APache MySQL modules are turned on using the control panel.
Type in "http://localhost/project/homepage.html" in a web browser to access the files correctly.
Note that "project" can be replaced with any name of the folder the application's files are in.

# Sprint 1 Functionality
First, make sure PHP is connected properly, like using XAMPP.
To run the program find the delivery-estimation-project folder in Users, enter it and click on homepage HTML file.
Click on "Modify List" and add and adjust information in the form.
After finishing, click on the "Add Item" button to see if the item was able to be added without any error.
Either possibility ends by clicking on "Add more items" to return back to the previous page.
After making entries, click on "calculations" to find the values using the list.
Calculations is currently unfinished.

#Limitations
Any information typed in the form in "Modify List" resets when "Add Item" is clicked.
Form is missing more options regarding packages.
